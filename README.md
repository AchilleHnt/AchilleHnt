### 🚀&nbsp; Projets Phares

- 💳 **[MiniWallet](https://github.com/AchilleHnt/miniwallet)** - Moteur de transferts Mobile Money testé en PHP Orienté Objet (Enums, exceptions, injection de dépendances, tests unitaires).
- 📊 **[Gestionnaire de Créances](https://github.com/AchilleHnt/gestion-creances)** - Application web architecturée en MVC fait main (Routeur, PDO, transactions SQL, sécurité contre les injections).
- 📦 **[Paquet FCFA (Composer)](https://github.com/AchilleHnt/fcfa-packagist)** - Bibliothèque PHP pour représenter, additionner, comparer et formater les montants en FCFA (gestion stricte des entiers).
- ⚙️ **[Checkout Mobile Money Test](https://github.com/AchilleHnt/mobile-money-checkout)** - Intégration FedaPay/KkiaPay avec gestion des webhooks signés et protection contre le double traitement (idempotence).
