### 🚀 Projets phares

- 💳 [MiniWallet](https://github.com/AchilleHnt/miniwallet)  
  Moteur de transferts Mobile Money développé en PHP orienté objet.  
  Contient : enums, exceptions, injection de dépendances, modularité et tests unitaires.

- 📊 [Gestionnaire de Créances](https://github.com/AchilleHnt/gestion-creances)  
  Application web MVC développée manuellement avec routeur, PDO, transactions SQL et protections contre les injections.

- 📦 [Paquet FCFA (Composer)](https://github.com/AchilleHnt/fcfa-packagist)  
  Bibliothèque PHP pour représenter, additionner, comparer et formater les montants en FCFA avec gestion stricte des entiers.

- ⚙️ [Checkout Mobile Money Test](https://github.com/AchilleHnt/mobile-money-checkout)  
  Intégration FedaPay / KkiaPay avec webhooks signés, protection contre les doubles paiements et gestion de l'idempotence.
